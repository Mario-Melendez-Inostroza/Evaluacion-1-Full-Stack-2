# Knight of Ruin

## Descripción

Knight of Ruin es un sitio web desarrollado para la evaluación de Desarrollo Fullstack II.

El proyecto presenta la propuesta de un videojuego RPG de fantasía oscura, utilizando una estética inspirada en los clásicos RPG de pixel art.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Estructura del proyecto

- `index.html`: página principal del sitio.
- `login.html`: formulario de inicio de sesión.
- `register.html`: formulario de registro.
- `css/style.css`: estilos y diseño visual del sitio.
- `js/login.js`: validaciones del formulario de inicio de sesión.
- `js/register.js`: validaciones del formulario de registro.
- `imgs/fondo.png`: imagen utilizada como fondo principal.

## Características

- Página principal con navegación.
- Diseño visual inspirado en RPG de fantasía.
- Formularios de inicio de sesión y registro.
- Validaciones mediante JavaScript.
- Diseño adaptable a distintos tamaños de pantalla.
- Navegación mediante hipervínculos.
